# Accurex Campaign Report Card

AI-assisted campaign report generator for Accurex Biomedical marketing executives.
Same visual style, fonts, and deployment pattern as the
[Distributor Order Report Card Generator](https://github.com/mis1-alt/distributor-report-card),
but produces a **campaign report** instead of an order report — generated once at
campaign launch (plan) and again at close (actual results), using the same inputs.

## What it produces

A single-page branded PDF with:

- KPI strip: This Year vs Last Year value, overall change %, top distributor, top HQ, low-performing HQ
- Distributor-wise LY vs CY table (qty & value) with a per-row recommended action
- **Smart Result** — AI-generated timeline and action list
- **Checklist** — AI-generated, modelled on the "MCC - Marketing Plan" structure (Back End
  Activities → SOP for Campaign → Execution → Front End Activities), with exactly
  one doer (from PMT) per task, referencing the Technical Handbook / Order Collection Handbook
  where relevant
- **Competitor analysis** for the product, generated by AI
- **Creative** section — execution stays with PMT; AI gives short feedback on a pasted creative
  draft if one is supplied

## Deploy to Streamlit Cloud (free, 5 minutes)

1. This repo is already on GitHub at `mis1-alt/accurex-campaign-report-card`.
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Click **New app** → select this repository → set main file to `app.py` → Deploy.
4. In the app's **Settings → Secrets**, add:
   ```
   ANTHROPIC_API_KEY = "sk-ant-..."
   ```
   This keeps the Platform API key out of the app itself. If you'd rather not store it as a
   secret, anyone using the app can also paste the key directly into the sidebar at runtime —
   it is only held in that browser session and never written to disk.
5. Share the app URL with your team.

## Sales file format expected

One sheet per distributor. Each sheet should contain two column blocks (Last Year and This
Year), each with a `Product`, `Qty`/`Quantity`, and `Amount`/`Value` column. The app scans the
first 6 rows of each sheet to auto-detect the header row and the column positions of each
block — it does not assume a fixed column letter, so small layout differences between sheets
are tolerated. If a sheet fails to parse, it is skipped rather than guessed at.

## Distributor → HQ mapping (optional)

The report's "Top HQ" / "Low-Performing HQ" KPIs need a mapping from distributor name to HQ.
Upload a CSV or Excel file with columns named `Distributor` and `HQ` in the sidebar. Without
one, those two KPIs show "No HQ mapping" and the rest of the report still generates normally.

## Notes

- Uses the same DejaVu Sans fonts (with ₹ support) and colour system as the distributor
  report app, so the two report types read as one family of internal reports.
- The AI sections call the Anthropic API directly (model `claude-sonnet-4-5-20250929`) using
  whichever key is supplied, and return structured JSON that drives the PDF — there is no
  free-text AI output pasted directly into the report.
